# Точка — автосервис в Курске

Сайт автосервиса «Точка», Курск, Кирпичная ул., 19. Делает [lovlyDev](https://lovlydev.github.io).

**Сайт:** https://lovlydev.github.io/tochka/

- React + TypeScript + Vite, собирается и публикуется GitHub Actions при каждом пуше в `main`.
- Цены, контакты и часы работы — в `src/data.ts`.
- Отдельные стили для телефона — `src/styles/mobile.css`.

```bash
npm install
npm run dev
```
